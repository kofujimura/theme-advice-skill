# 藤村ゼミのテーマ指導

## このスキルで採用する方針

対象は卒研テーマを考えるゼミ3年生。4年次に、本人が説明できる研究の主張と、それを支える結果を得られるようにする。期間や人数、予算は学生・教員に確認し、学年から自動で設定しない。

主な接点はAI活用、ブロックチェーン、電子価値取引。メディアアートも対象。学生の生活や異分野の経験と接続する。技術への関心だけを入口にしない。

教員の共有文書は、成果の新しさを次の3種類で説明する。

- **技術の新しさ**：既存課題に対する方法・仕組みの改善。
- **応用の新しさ**：技術の適用によって、新しい価値や使い方を実証する。
- **問題の新しさ**：従来十分に問われていない問題や課題を見つけ、取り組む。

今回の指導では、特に新しい問題を発見することを重視する。新しい技術を使うだけでは、研究の貢献は確定しない。既存テーマの新しい条件・失敗・評価にも未知の問いがあり得る。

アプリ開発は実験の手段として位置付ける。何を作るかと並行して、何を明らかにするか、どう確かめるかを考える。AIによって実装を早められる可能性はあるが、期間や品質を保証しない。

メディアアートでは、新しい表現・鑑賞体験・作品の完成度を成果として扱う。有用性を必須にしない。制作意図、既存作品との違い、鑑賞者との相互作用を記録する。
